📊 Data Analyzer and Transformer

Welcome to the Data Analyzer and Transformer 🐍✨

This is a beginner-friendly Python project that allows you to enter numbers and perform different operations such as statistics, factorial calculation, filtering, and sorting.

🚀 Features

This project includes:

📝 Input Data — Enter numbers into the program.
📊 Data Summary — Find total elements, minimum, maximum, sum, and average.
🔢 Factorial — Calculate factorial using recursion.
🔍 Filter Data — Filter numbers using a threshold and a lambda function.
📈 Sort Data — Sort numbers in ascending or descending order.
📋 Dataset Statistics — Return multiple statistical values using a tuple.
❌ Exit — Close the program safely.

▶️ How to Run
1️⃣ Install Python

Make sure Python is installed on your computer.

2️⃣ Open the project

Open pr 4.py in VS Code or another Python editor.

3️⃣ Run the program

Open the terminal and run:

python "pr 4.py"
📋 Main Menu

When you run the program, you will see:

Main Menu:

1. Input Data
2. Display Data Summary (Built-in Functions)
3. Calculate Factorial (Recursion)
4. Filter Data by Threshold (Lambda Function)
5. Sort Data
6. Display Dataset Statistics (Return Multiple Values)
7. Exit Program
📝 Option 1: Input Data

Enter numbers separated by spaces.

Example:
Enter data for a 1D array:
10 20 30 40 50

The numbers are stored in a Python list.

📊 Option 2: Display Data Summary

This option calculates:

🔢 Total number of elements
🔽 Minimum value
🔼 Maximum value
➕ Sum
📈 Average
Example:
Data Summary:
- Total elements: 5
- Minimum value: 10
- Maximum value: 50
- Sum of all values: 150
- Average value: 30.00
🔢 Option 3: Calculate Factorial

This option calculates the factorial of a number using recursion.

Example:
Enter a number to calculate its factorial: 5

Factorial of 5 is: 120

The program uses the function:

factorial_recursive(n)
🔍 Option 4: Filter Data

This option filters numbers based on a threshold using a lambda function.

Example:

If the data is:

10 20 30 40 50

and the threshold is:

30

The output will be:

Filtered Data (values >= 30):
30, 40, 50
📈 Option 5: Sort Data

You can sort your data in two ways:

1️⃣ Ascending Order
10, 20, 30, 40, 50
2️⃣ Descending Order
50, 40, 30, 20, 10

The program uses Python's sorted() function.

📋 Option 6: Dataset Statistics

This option uses a function that returns multiple values:

min_val, max_val, sum_val, avg_val = get_dataset_statistics(data)

It displays:

Dataset Statistics:
- Minimum value
- Maximum value
- Sum
- Average
❌ Option 7: Exit

Choose option 7 to close the program.

Thank you for using the Data Analyzer and Transformer Program. Goodbye!
