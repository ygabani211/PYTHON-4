# 📊 Data Analyzer and Transformer Program

Welcome to the **Data Analyzer and Transformer Program**! 🐍✨

This Python project is a simple **menu-driven data analysis program** that allows you to enter a 1D dataset and perform different operations such as calculating statistics, factorial, filtering, sorting, and more.

---

## 🚀 Features

The program provides the following options:

1. 📥 **Input Data** – Enter numbers into a 1D array.
2. 📊 **Display Data Summary** – Shows total elements, minimum, maximum, sum, and average using built-in functions.
3. 🔢 **Calculate Factorial** – Calculates factorial using **recursion**.
4. 🔎 **Filter Data by Threshold** – Filters values using a **lambda function**.
5. 📈 **Sort Data** – Sorts data in ascending or descending order.
6. 📋 **Display Dataset Statistics** – Returns minimum, maximum, sum, and average values.
7. 🚪 **Exit Program** – Safely closes the program.

## 🔎 Filter Example

If the threshold is:

```text
5
```

The program displays:

```text

11, 10, 9, 40, 58, 53
```

## 📈 Sorting Example

### Ascending Order

```text
9, 10, 11, 40, 53, 58
```

### Descending Order

The program can also sort the dataset from highest to lowest. 🔽

## 🔢 Factorial Example

For:

```text
9
```

The program calculates:

```text

```

This calculation is performed using **recursion**. 🔁
